# Projeto de QA Manual — Cadastro de usuário

**Status: projeto educacional concluído (versão 1).**

## Sobre o projeto

Este é um projeto educacional de qualidade de software. Ele simula o teste
manual de uma tela de cadastro de usuário.

O projeto não contém um sistema real nem código. As regras, os testes e os
resultados serão documentos simulados para demonstrar o raciocínio de QA de
Andeil Abreu.

## Objetivo

Praticar e demonstrar:

- leitura e definição de requisitos;
- criação de cenários e casos de teste;
- testes positivos e negativos;
- teste de valores-limite;
- registro de resultados;
- documentação de bugs;
- classificação por severidade e prioridade;
- reteste e regressão.

## Tela simulada

A tela terá inicialmente:

- campo Nome;
- campo E-mail;
- campo Senha;
- botão Cadastrar.

Os requisitos iniciais estão definidos e 34 casos de teste foram documentados e
executados de forma simulada: 31 foram aprovados e 3 foram reprovados.

## Documentos do projeto

- `requisitos.md`: regras que o cadastro deverá cumprir.
- `casos-de-teste.md`: casos de teste planejados.
- `resultado-dos-testes.md`: execução e resultado dos testes.
- `relatorio-de-bugs.md`: defeitos simulados encontrados.
- `reteste-e-regressao.md`: confirmação das correções e verificação de possíveis
  impactos em funcionalidades já aprovadas.

## Avisos

- Todos os dados usados serão fictícios.
- Bugs e resultados simulados serão identificados claramente.
- O projeto não apresentará estudo como experiência profissional.
- Nenhum dado de antigos clientes será utilizado.
