# Relatório de bugs

## Situação atual

Nenhum bug foi registrado.

O sistema deste projeto é simulado e os casos ainda não foram executados.
Quando forem criados exemplos simulados, eles serão identificados claramente
para não serem confundidos com defeitos encontrados em uma aplicação real.

## Estrutura que será utilizada

Cada bug deverá informar:

- identificador;
- título;
- requisito relacionado;
- ambiente;
- pré-condição;
- passos para reprodução;
- resultado esperado;
- resultado obtido;
- severidade;
- prioridade;
- evidência;
- status.
